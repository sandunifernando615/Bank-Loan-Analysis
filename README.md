📊 Project Overview

This project presents an interactive Bank Loan Analysis Dashboard developed using Tableau.

The dashboard provides an overview of loan applications, funded amounts, received payments, interest rates, debt-to-income ratios, and loan performance. It also allows users to explore loan applications by month, state, loan term, employee length, loan purpose, and home ownership.

💡 Key Insights

The majority of loan applications fall into the Good Loan category.
Debt consolidation is the largest loan purpose, followed by credit card loans.
36-month loans represent a larger share of applications than 60-month loans.
Rent and mortgage are the major home-ownership categories represented in the applications.
The dashboard provides detailed loan-level information including purpose, home ownership, grade, sub-grade, issue date, loan amount, interest rate, installment, and total payment.


🎯 Project Objective

The objective of this project is to transform loan data into an interactive business intelligence dashboard that enables users to monitor loan performance, identify trends, and understand the characteristics of loan applications.

Dashboard Tool: Tableau
